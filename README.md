# 🛋️ ARDeco – AI-based Smart Interior Design Tool

🚀 *An AI-powered real-time segmentation, measurement, and recoloring tool for interior design using Web-based Augmented Reality.*

---

## 📌 Overview

**ARDeco** is a research-driven, real-time **smart interior design tool** developed as part of a remote internship with **Star Maven Digital** from **January to May 2025**.  
It combines **Deep Learning**, **Computer Vision**, and **AR** to enable intelligent surface segmentation, recoloring, and spatial measurement using a standard mobile/web camera.

---

## 🔬 Core Technologies

- **Computer Vision**: OpenCV, Pillow
- **Deep Learning**: PyTorch, TensorFlow
- **Pretrained Models**: YOLOv5, U-Net, RCNN, SAM (Segment Anything Model)
- **Model Training**: ADE20K Dataset
- **Backbones Evaluated**: MobileNet, ResNet, DeepLabV3
- **Chosen Model**: DeepLabV3 (for real-time performance and precision)
- **AR Platform**: Unity3D with AR Foundation
- **Web Integration**: WebAR, Streamlit (for visualization and testing)

---

## 🛠️ Features

- ✨ **Real-time AI segmentation** of walls, floors, and furniture surfaces
- 🎨 **Interactive recoloring** to preview interior design choices instantly
- 📏 **AR measurement tools** using Unity plane detection & raycasting
- 🌐 **Optimized for web deployment** under constrained mobile environments
- 🧠 **Efficient model integration** with reduced latency and high usability

---

## 📈 Project Outcomes

- Developed a prototype system integrating **AI models with AR rendering**
- Built end-to-end tool for **designers, architects, and AR-based apps**
- Successfully deployed ARDeco in browser via **WebAR pipeline**
- Explored and compared model architectures for real-time applications
